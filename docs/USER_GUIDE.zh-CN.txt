KeyPulse
========

直接双击 KeyPulse.exe 即可运行，无需安装。
这是本地生成的未签名程序；若 Windows 首次显示 SmartScreen 提示，请确认文件来源后选择“更多信息”→“仍要运行”。

使用方法
--------
1. 打开程序后，按键次数会自动开始统计。
1.1 右上角的 MONITOR / GALLERY 开关用来切换控制台的两个界面：MONITOR 是正在统计的
   设备，GALLERY 是历次重置后存下来的存档（见「画廊」一节）。
2. 控制台左侧的 SHOW 开关用来切换看键盘（KEYBOARD）还是看手柄（GAMEPAD）。
   两边各自独立计数：切到手柄时键盘照样在统计，反过来也一样。
   每次打开程序都从键盘这一面开始，不管上次关窗口时停在哪一面——反正两边一直都在
   统计，切到哪一面看只是看法，不必替你记住。
3. 看键盘时，右边的 LAYOUT / 配列 可切换四种常见配列，按键数从多到少排：
   全尺寸（104 键）、TKL（87 键，去掉小键盘的紧凑型）、
   75%（83 键，保留功能键行、方向键收进右下角）、60%（61 键，只留字母与符号区）。
   四种都照着常见实物的按键摆位画。
4. 打开或切换配列时，键盘会自动放大到接近填满窗口——留一圈余白，不贴到白板边上。
   键盘区域是一块固定大小的白板：把鼠标放在上面滚动滚轮，只有键盘（或手柄）本身跟着放大缩小，白板和窗口都不会跟着变；指针下的位置在缩放时保持不动。放大到超出白板后，按住鼠标左键拖动即可平移查看。
4.1 右上角的 LIGHT 开关用来开关灯光：关掉后键盘不再跑彩虹光波、按键也不再有白光
   爆闪，只留下键帽上的热力配色；手柄同理，灯会全部熄灭。灯关掉时不再逐帧重绘，
   基本不占 CPU。键盘和手柄各记各的，互不影响，下次打开还是上次的状态。
   全新安装时灯默认是关着的：第一眼先看清键盘和数字，想看灯光随时打开，打开之后
   这个选择就一直留着。
5. 打开“开机自启”，下次登录 Windows 后会自动在后台运行。第一次运行时程序会替你
   打开它——不然第一天的统计就少了开机到手动双击之间那一段。这只在第一次运行时
   做一次：之后你把它关掉，它就一直是关着的。
6. 关闭窗口时程序会缩到右下角托盘继续统计；右键托盘图标并选择“退出”才会停止。
7. 键盘按透视角度立体呈现：远端更小更高，靠近自己的更大，会露出侧面；手柄则是
   正面平视，厚度全靠明暗表现，不露侧面。

语言（中文 / English）
----------------------
界面自带中、英两套文字。顶栏最右侧（RESET / 重置 旁边）的小按钮就是语言开关：界面是
英文时它显示“中文”，点一下整套界面换成中文；界面是中文时它显示“EN”，再点一下
换回英文。按钮上写的永远是“点它会变成的那种语言”，所以不用再在旁边放说明文字。

1. 换语言不会改动任何数据文件：stats.json、settings.json，以及每份存档的
   .json 那一半，里面记的始终是英文。存档的 .png 那一半是例外，也是故意的：
   它不是数据，而是当时那块控制台的照片，所以存的时候界面是中文，图也就是
   中文的；图背后的计数两种语言下读到的都一样。
2. 中文和英文一样短：按钮、卡片、弹窗都是几个字的词，界面不会因此变大变挤。
3. 选好的语言会写进 settings.json，下次打开还是它。

键盘灯光
--------
键盘做成了主流机械键盘那种「轴下 RGB」：光从每个键帽四周的缝里透出来，落在浅色
定位板上晕开，和白色键盘开灯后的样子一致。

1. 全键盘一条彩虹光波从左上往右下缓缓扫过，约 5 秒走完一轮，然后循环。
2. 光只出现在键帽之间的缝隙和键帽根部，不会盖在键帽上——键帽留给热力配色，哪个键
   按得多一眼就能看出来，两者不抢。
3. 灯装在每颗轴下面，所以只有按键周围那一小圈定位板会亮，往外很快淡掉。像小键
   盘和主键区之间、方向键四周这种没有按键的大片空白，定位板就是它本来的颜色，
   不发光——整块板子一起泛光是不对的。
4. 每敲一下，那颗键的轴位会瞬间白光爆一下再落回光波里，连打时能看到一串火花。
5. 灯光分上下两层：上层是键帽缝隙里那层跟着彩虹光波流动的光；下层是外壳侧面的灯带
   和它洒在桌面上的光晕，固定为控制台的青绿色，不跟着光波变色。
6. 灯光只在窗口打开时运行；缩到托盘后完全停下，不占 CPU。
7. 键帽上的字不发光：那里印的是按键次数，要保证任何光色下都看得清。
8. 不想要灯就把 LIGHT 关掉：上下两层和按键白光一起熄灭，侧面只剩下不发光的白色导光
   条，键帽热力配色照常。RESET 存档时存的就是当时屏幕上的样子——关着灯存下来的那一
   张，画上的键盘也是暗的。

手柄统计
--------
把 SHOW 切到 GAMEPAD，就能看到手柄。外形、颜色、每一处高光和阴影都照着参考图
1:1 复刻：白色外壳配薄荷绿按键，扳机上是磨砂颗粒面，摇杆是滚花圈加碗形帽。

1. 每个按键都写着自己的次数。LT / LB / RT / RB 的数字印在那四根条子里，参考图
   本来就是这么画的；其余按键（ABXY、十字键四个方向、LS / RS、
   View / Menu）按键面上仍然只有自己的字符，数字挂在旁边一枚小圆牌上，用一根细线
   连回按键——牌子摆在按键旁边那块空外壳上，不压住任何东西。数字的写法和键盘
   一致：过万才简写（中文 1.1万 / 2.4亿，英文 11.3K / 2.4M）。按下时牌子会跟着
   按键一起亮。
2. 按下任何一个键，画面上对应的那一处会亮一下再退回原色；除此之外手柄一直保持
   参考图上的那套配色，不做热力深浅变化。
3. MODEL 里可以切换四种常见手柄：Xbox、PlayStation（DualSense）、Switch Pro、
   Wired（通用有线手柄）。四款共用同一副外壳，换的是按键的名字和摆位——例如
   PlayStation 的十字键在左上、两根摇杆并排在下方，PS 键落在两根摇杆中间；次数
   是同一份，不会因为切换而重置或分家。
3.1 Wired 和 Xbox 的摇杆、十字键、ABXY 摆位是一样的，这不是画重了：Windows 认成
   XInput 的手柄，在这个正视图上本来就是一台 Xbox 手柄，这正是「通用」的意思。
   照参考图，两者的区别画在别处——Wired 顶上有一根线，View/Menu 位置是 Back/
   Start，下面多一对 Turbo / Mode 小圆键；Xbox 则是 View/Menu 加中间一颗 Share，
   Xbox 键有背光环，下面还有配对小圆点。
4. 支持任何被 Windows 认成 Xbox 手柄（XInput）的设备：Xbox 手柄、大部分 PC 手柄，
   以及通过 Steam 或 DS4Windows 等工具映射后的 PS / Switch 手柄。
5. 统计的按键包括：ABXY 四个面键、十字键四个方向、LB/RB、LT/RT 扳机、左右摇杆按下
   （L3/R3）、Start / Back、Home 键。不同外形上的名字不一样（例如 A 在 PlayStation
   上显示为 ✕，在 Switch 上显示为 B），但记的是同一个物理位置。
6. 摇杆推动时，画面上的杆帽会跟着往同一个方向倾斜，底座只跟一点点——和真手柄一样
   是绕根部转的；只有按下摇杆才会计数。
7. 扳机是模拟量，按到约 1/6 行程才算一次；松开一点不会重复计数。按下时上方那片
   扳机面也会跟着亮。
8. 标题旁的状态灯只说一件事：当前看的这台设备是不是正在被读。接上手柄后显示
   “● 监听中”（和看键盘时一样），鼠标悬停上去会告诉你它是几号手柄；没接则显示
   一枚淡黄色的“○ 未连接手柄”标签。手柄可以随时插拔，程序每秒会重新找一次。
9. 中间那圈六边形刻线、Xbox 键下面的小圆点、Share / Turbo / Mode 三颗小键、
   Switch Pro 的截图键、以及 Wired 顶上那根线，都只是外壳上的造型，不参与计数
   ——XInput 本来就不上报它们。
10. Xbox 键（PS 键 / Home 键）是唯一的例外：它的次数照常记，但按参考图不在手柄上
   写数字。想看它按了多少次，去 TOP BUTTON 卡片或存档里。

手柄灯光
--------
手柄不套用键盘那套 RGB，只画官方那一款手柄本来就有的灯，没有的就不画：

- Xbox：只有中间的 Xbox 键是背光的，画成球标外面那一圈淡蓝色亮环。
- PlayStation：中间两侧的灯条，会跟着彩虹光波变色——这是四款里唯一会变色的灯。
- Switch Pro：中间上方一排四个玩家指示灯，接一个手柄时只亮第一格，其余三格是暗槽。
- Wired：通用有线手柄本身没有任何灯，所以一盏都不画。

如果你的手柄（例如北通 40 御铠）自带 RGB，而外形选的是 Xbox，画面上不会显示那圈
灯——这里画的是官方原型，不是第三方改款。

切到 GAMEPAD 时，右上角的 LIGHT 开关管的就是手柄这几盏灯：关掉后灯位只剩下不发光的
暗槽，和真机关机时一样。

重新开始计数
------------
右上角的 RESET 按钮可以把当前正在看的那个设备重置，重新开始一轮统计。
看键盘时按 RESET 只清键盘，看手柄时只清手柄，另一边不受影响。

1. 点击 RESET，程序会先说明这一轮共有多少次敲击，确认后才会重置；误点时选“Cancel”即可。
2. 重置前，本轮数据会先存进 KeyPulse.exe 旁边的 snapshots 文件夹；只有存盘成功才会
   真正重置。键盘存进 snapshots\keyboard，手柄存进 snapshots\gamepad，两台设备各一格。
3. 重置后可直接点“Open gallery”进入画廊，刚存下的那一张贴在相册的最后，界面会自动
   滚到那里。
4. 每按一次 RESET 就多一份存档，旧存档不会被覆盖，可以长期对比历次统计。

每次存档是同名的一图一表，各自放在所属设备的文件夹里，例如：

  snapshots\keyboard\keypulse-2026-08-30_132020.png   重置前那块键盘的样子（双击就能看）
  snapshots\keyboard\keypulse-2026-08-30_132020.json  同一份数据的明细（想再统计时用）

手柄的存档在另一个文件夹里，文件名也多一段 gamepad，不会和键盘的混在一起：

  snapshots\gamepad\keypulse-gamepad-2026-08-30_132020.png
  snapshots\gamepad\keypulse-gamepad-2026-08-30_132020.json

图片就是按下 RESET 前键盘的完整画面：每个键上的次数、深浅热力配色、上方的
TOTAL / TODAY / TOP KEY 三张卡片，加上归档时间、键盘配列和统计起止日期。
不论当时窗口开多大，图片都按固定尺寸渲染，清晰度一致。

图片保存的是你当时正在看的那个配列。比如你看的是 TKL 87，而这一轮又敲过小键盘，
那些键不会出现在图上——但一次不漏地记在 .json 里。

.json 用记事本或浏览器就能打开，里面包含：
- ranking：按次数从多到少排好序的按键列表，带界面上显示的键名
- keys：每个按键的次数（与 stats.json 结构相同）
- daily_totals：本轮每天的总次数
- total_keystrokes / distinct_keys / covers：本轮总次数、涉及的按键数量、起止日期
- started_at / archived_at：本轮第一次敲击的时间、点 RESET 归档的时间
- layout / layout_name：归档时画面上用的配列（手柄则是外形）

画廊（GALLERY）
---------------
右上角切到 GALLERY，就是历次存档的相册：每重置一次，那一轮的画面就洗成一张照片贴上
墙。第一次重置得到的那张贴在左上角，之后每一张顺着上一张往右排，排满一行再从下一行
最左边接着排——和翻一本相册的顺序一样。

1. 墙上的 KEYBOARD / GAMEPAD 分开陈列，键盘的一面墙，手柄的另一面墙，互不混放。
   右边的 FOLDER 按钮打开的就是当前这面墙对应的那个文件夹（keyboard 或 gamepad）。
2. 每张照片都是裱好的：白卡纸开一个窗把照片嵌在里面，窗口边上压一道极浅的裱边阴影，
   下方留一条更宽的裱框，上面左边写归档日期、右边写这一轮的总次数（过万简写成
   1.4万 / 14.5K）。字写在裱框上而不是压在照片上，鼠标移上去整张照片会浮起来，
   日期变深、次数变绿。编号、按键数量等其余细节都收进详情页。
3. 一行排几张由窗口宽度决定（常见窗口下键盘 3 张一行、手柄 4 张一行），同一面墙上的
   照片一律裁成同一个尺寸，行与行对齐；窗口拉大拉小，照片会跟着重排。
4. 点开任意一张照片，就是这一轮的详情页：
   - 左边是完整大图和本轮按得最多的几个键（BUSIEST）
   - 右边的 EXHIBIT LABEL 写着起止时间 —— Counted from（本轮第一次敲击的时间）、
     Counted until（点 RESET 归档的时间）、Span（这一轮持续了多久）、涉及的日期范围、
     总次数、按键数量、设备和配列、文件名。最忙的键不在这里重复，
     它就是左边 BUSIEST 的第一行
   - 右下是这一份存档的 .json 全文，可以直接翻看；COPY JSON 一键复制全文
5. SHOW FILE / 定位文件 会在资源管理器里打开存档所在的文件夹并选中它；REMOVE 会连图带表一起删掉这一份存档（会先确认，
   删掉不可恢复）。删除是从磁盘上删：程序用过的每个位置里的同名存档都会一起删掉，
   否则旧位置里留下的那一份会在下次启动时被收回来，等于没删。按 Esc 或左上角的
   ← WALL 回到墙面。
6. 更早版本存下的旧存档也能挂上墙；只是那时还没有记录起始时间，Counted from 会
   显示本轮的第一天并标注 (first day)。

数据位置
--------
所有持久数据都保存在 KeyPulse.exe 旁边。把 exe 放在哪里，数据就在哪里：

  KeyPulse.exe
  stats.json          每个按键的累计次数和每日总次数，以及本轮从什么时候开始算
                      （started_at）；手柄的数据放在同一个文件的 devices.gamepad 里，
                      键盘的仍在最外层，老版本的 stats.json 可以直接继续用
  settings.json       配列 / 外形、缩放比例、灯光开关、界面语言等设置
  snapshots\keyboard\  键盘每次 RESET 前自动保存的存档（一张 .png 图 + 一份 .json 明细）
  snapshots\gamepad\   手柄的同上；两台设备各一格，不混放

画廊里挂的就是这两个文件夹里的东西：在这里删掉文件，墙上对应的那张照片也就没了。

位置是从 KeyPulse.exe 自己的路径算出来的，不是 Windows 启动时给程序的“当前目录”——
早期版本跟着当前目录走，开机自启动和手动双击打开时会存到两个不同的地方，看上去就像
画廊里的东西凭空没了。后来的版本改成写死 D:\KeyPulse，路径是稳了，可那是一个谁也没
指定过的文件夹，换台电脑、换个盘都一样往那儿放。现在两个毛病都没有了：数据跟着程序
走，删掉程序所在的文件夹就等于全部删干净。

如果 exe 被放在写不进去的地方（比如 Program Files），程序不会因此打不开，而是退到
%LOCALAPPDATA%\KeyPulse 继续记。

从旧版本升级过来不用手动搬家：每次启动都会顺带检查程序以前用过的几个位置（包括
D:\KeyPulse），把落在那里的存档复制回来、按设备归进 keyboard / gamepad 两个文件夹，
并且把其中更新的那份 stats.json / settings.json 一并接过来。存档只复制、不删原件，
同名的不覆盖。确认画廊和计数都在之后，D:\KeyPulse 就可以自己删掉了。

隐私说明
--------
KeyPulse 只记录“哪个物理按键按了几次”，不记录文字、密码、聊天内容或按键顺序。

注意
----
- 长按一个键时，只按物理按下次数计数，不把 Windows 自动连发算成多次。
- 手柄同时接了多个时，只统计第一个被找到的；拔掉后会自动切到下一个。
- 手柄的“摇杆推动方向”只用来显示，不计入次数——否则打一局游戏就会有几十万次。
- 笔记本的 Fn 键通常由键盘固件处理，Windows 无法可靠监听，因此 Fn 键可能始终显示为 0。
- 若移动了 KeyPulse.exe，请重新关闭并打开一次“开机自启”，以刷新启动路径。
- 需要保留历史时，备份 exe 旁边的 stats.json 即可；点 RESET 时程序会自动备份一份到 snapshots。
- RESET 只清空当前统计，不会删除 snapshots 里已有的存档。
